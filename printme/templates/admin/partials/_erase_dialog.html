{# Manual "snip" tool: freehand erase directly on an already-processed photo, for a leftover background-removal artifact or a stray object the automatic crop caught. Shared dialog (like every other admin dialog), opened from a job card's "Erase" button, the flagged-job review page, or a Photo Sheets item hotspot - photo-erase.js exposes openEraseDialog() precisely so all three can reuse it. The image/canvas wrapper's aspect-ratio is set to the real photo's natural dimensions in JS before drawing starts - without that, an object-contain image can letterbox inside a differently-shaped box, and a canvas overlay sized to the whole box (not just the visible image content) would misalign every stroke's fraction coordinates once mapped back to the real photo server-side. #}
